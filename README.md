# Anwar Ibrahim — Personal Portfolio

A responsive, accessible academic and professional portfolio for Anwar Ibrahim,
Machine Learning Researcher and Engineer.

## Structure

```text
.
├── index.html
├── style.css
├── script.js
├── robots.txt
├── sitemap.xml
├── assets/
└── README.md
```

The site is intentionally build-free: GitHub Pages can serve the repository root
directly without Node.js, a framework, or a deployment bundle.

## Preview locally

From the repository directory, run:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Publish with GitHub Pages

1. Push the files to the `main` branch of `Anwar9Ibrahim.github.io`.
2. In the GitHub repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select `main` and `/ (root)`, then save.

The site will be available at <https://anwar9ibrahim.github.io>.
